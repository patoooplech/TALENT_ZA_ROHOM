# TALENT_ZA_ROHOM
Hlavný návrh aplikácie má byť na to že sa majú skladať skupiny a zakladať skupiny pre talenty v blízko okolí, vlastne si tam budeš vedieť vytvárať profily kde budeš mať možnosť zadať svoju adresu kôli lepšiemu výpočtu talentov a podobne, taktiež tam bude možné zadať proste nejakú oblasť záujmu
